# CRM службы эксплуатации здания

Одностраничное веб-приложение для диспетчерской службы эксплуатации здания (пример: БЦ «Северная Башня»).

## Возможности

- **Обзор** — ключевые показатели, разрез здания с открытыми заявками по этажам, ближайшее плановое ТО.
- **Заявки** — список и доска по статусам, поиск и фильтры, сроки SLA по приоритету (аварийная 2 ч, высокая 8 ч, обычная 24 ч, низкая 72 ч), назначение исполнителя, комментарии и история.
- **Плановое ТО** — график регламентных работ с отметкой выполнения.
- **Оборудование** — реестр инженерных систем с состоянием и созданием заявки по оборудованию.
- **Персонал** — карточки сотрудников с редактированием, добавлением и удалением, доступность и загрузка.

## Запуск

Откройте `index.html` в браузере. Сборка и сервер не нужны.

Данные хранятся в `localStorage` браузера; кнопка «Сбросить к примеру» возвращает демонстрационные данные.
